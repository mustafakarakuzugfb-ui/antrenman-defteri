# Antrenman Defteri

Spor İstanbul 1 aylık programım için set / kg takip uygulaması. Her alet için hareket animasyonu içerir.

- Uygulama ekranı: `app/src/main/assets/index.html`
- Her `main` dalına gönderimde GitHub Actions APK'yı derler ve **Releases** sayfasına `AntrenmanDefteri.apk` olarak koyar.
- Kayıtlar telefonda saklanır. Uygulamayı silmeden önce **Gelişim → Yedek → Yedeği dışa aktar** ile yedek al.
